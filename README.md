# Open card sort

A standalone card-sorting workspace for baby-monitor menu items.

## Use

Open `index.html` locally or use the GitHub Pages website:

https://wx-ph.github.io/open-card-sort/

- Drag cards into groups and name each group.
- Select **Edit cards** to edit titles/descriptions, add cards, or remove them.
- **Save changes** keeps card edits in the current browser; **Cancel** discards unsaved edits.
- Export the current sorting results as CSV.
- **Reset** clears groups while retaining the saved cards.

## Storage and privacy

This is a static page. Sorting and edits are stored in the visitor's browser using local storage; they are not sent to GitHub or shared between teammates. Browser data is not included in this repository. Use **Export CSV** to share results.

The repository and GitHub Pages site are public.

## Font

The page uses Neue Frutiger World when it is installed on the visitor's device and falls back to Arial/sans-serif otherwise. No commercial font files are embedded or redistributed.

## Publishing

GitHub Pages serves the root of the `main` branch. Commit and push changes to `index.html` to update the website. No dependencies or build step are required.
